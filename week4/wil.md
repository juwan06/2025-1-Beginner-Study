개발 입문 스터디 4주차
============

## branch 전략

git flow
========
main : 본체

develop: 개발중인 본체(검수 어느정도 된 것)

feature: 진짜 개발중인 곳(검수 필요)

hotfix: main 버그 빠르게 고치는 곳(검수되지 못한 버그를 배포 후 픽스)

release: 개발 완료된 버전. (마지막 검수)

github flow
=====================
main: 본체

feature: 개발중

빠꾸없이 개발 후 병합


developer's attitude
==================
프로그램이 잘 굴러가도록 코드 작성

다른 사람도 유지 보수가 용이하도록 코드 작성

모르는 건 최대한 구글링 해보고 질문

무엇을 모르는지 구체화하며 좋은 질문하려고 노력하기

개발 입문 스터디 소감
==================
친구들이랑 개발을 하려고 모여도 github사용법이 막연해 파일공유에 많은 시간이 들었습니다. 하지만 이 스터디를 들은 후 github는 제 머릿 속에 막연한 것이 아닌, 편리한 협업툴로써 자리잡았습니다. 이번 스터디에서 github의 repository 시스템부터 차근차근 배우며 개발자의 기본 소양을 갖춘 것 같아 뿌듯합니다. 
 
 이런 스터디를 준비해주신 조상욱 멘토님게 감사의 말씀을 드립니다.
